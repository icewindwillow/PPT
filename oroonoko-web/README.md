# Oroonoko Through the Traveller's Eye

An English interactive web presentation of the supplied Oroonoko travel-writing manuscript.

## Run locally

From this folder:

```bash
python3 -m http.server 4173 --directory dist
```

Then open <http://127.0.0.1:4173/>.

The presentation is a single static page. Use the sidebar, the `Evidence` button, or the left and right arrow keys to move through the eight scenes.
